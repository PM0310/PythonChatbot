# Sales Order Assistant - Refactoring Documentation

## Overview
This document outlines the refactoring done to the Sales Order Chatbot (`app7.py`) to improve code organization, maintainability, and flexibility.

## Key Changes

### 1. New Module: `system_prompts.py`
**Purpose**: Centralized management of all system prompts used by AI/LLM models.

**Contents**:
- `INTENT_EXTRACTION_SYSTEM_PROMPT` - Prompt for extracting user intent from natural language
- `DYNAMIC_SQL_GENERATION_SYSTEM_PROMPT` - Prompt for generating Oracle SQL queries with Oracle Apps standard tables
- `AI_SUMMARY_GENERATION_PROMPT` - Prompt for generating executive summaries
- `HELP_PROMPT` - Available commands and examples
- `ORACLE_APPS_SCHEMA_REFERENCE` - Documentation of Oracle Apps standard tables

**Benefits**:
- Easy to update prompts without modifying app logic
- Centralized prompt management
- Version control friendly for prompt iterations
- Reusable across multiple applications

**Usage**:
```python
from system_prompts import INTENT_EXTRACTION_SYSTEM_PROMPT
from system_prompts import build_intent_user_prompt
```

### 2. New Module: `config_manager.py`
**Purpose**: Centralized configuration management with validation and organization.

**Features**:
- Singleton pattern for single configuration instance
- Configuration groups for better organization:
  - `database` - Database connection settings
  - `api` - REST API endpoints and credentials
  - `ai_llm` - AI/LLM model configuration
  - `oracle_apps` - Oracle Apps parameters
  - `email` - SMTP and email settings
  - `voice` - Voice recognition settings
  - `scheduler` - Scheduled task settings
  - `app` - Flask application settings

**Key Methods**:
- `load_config()` - Load configuration from file
- `get_config_value(key, default)` - Get a configuration value
- `set_config_value(key, value)` - Set and persist configuration
- `get_config_group(group_name)` - Get a configuration group
- `get_org_id()`, `get_order_type_id()`, etc. - Helper functions for common config values

**Benefits**:
- Single source of truth for configuration
- Automatic persistence to `config.json`
- Type-safe configuration access
- Easy to add new configuration groups

**Usage**:
```python
import config_manager

# Get a value
host = config_manager.get_config_value("db_host")

# Set a value
config_manager.set_config_value("db_host", "new_host")

# Get a group
oracle_config = config_manager.get_config_group("oracle_apps")
```

### 3. Refactored `app7.py`
**Changes**:
- Imports `config_manager` and `system_prompts` modules
- All configuration access now through `config_manager`
- All system prompts now imported from `system_prompts`
- Database functions remain for backward compatibility but can be removed
- All AI functions use centralized prompts

**Migration Path**:
- Old direct config access removed and replaced with `config_manager` calls
- Old hardcoded prompts replaced with centralized versions
- All endpoints updated to use new modules

## Oracle Apps Standard Tables

The refactored application now focuses on Oracle Apps standard tables for dynamic SQL generation:

### Sales Order Tables
- `OE_ORDER_HEADERS_ALL` - Order headers with order number, status, dates
- `OE_ORDER_LINES_ALL` - Order line items with inventory and quantity info
- `OE_ORDER_STATUSES` - Status lookup values

### Customer Tables
- `HZ_PARTIES` - Customer party information
- `HZ_CUST_ACCOUNTS` - Customer account details
- `HZ_CUST_ACCT_SITES` - Customer site addresses
- `HZ_PARTY_SITES` - Party site locations

### Inventory Tables
- `MTL_SYSTEM_ITEMS_B` - Item master records
- `MTL_SYSTEM_ITEMS_TL` - Item translations
- `MTL_ONHAND_QUANTITIES` - On-hand inventory

### Setup/Organization
- `HR_OPERATING_UNITS` - Operating unit definitions
- `FND_LOOKUP_VALUES` - Lookup values for dropdowns

**Note**: All dynamic SQL queries generated by the AI now use these standard tables instead of custom or proprietary tables.

## Development Workflow

### Adding a New Configuration Value
1. Add to `DEFAULT_CONFIG` in `config_manager.py`
2. Optionally add to a config group
3. Use `config_manager.get_config_value(key)` in app code
4. Automatically persists to `config.json`

### Updating AI Prompts
1. Edit the prompt in `system_prompts.py`
2. No need to modify `app7.py`
3. Changes take effect on next prompt generation

### Adding Oracle Apps Tables
1. Document the table in `ORACLE_APPS_SCHEMA_REFERENCE`
2. Update `DYNAMIC_SQL_GENERATION_SYSTEM_PROMPT` with table info
3. AI will automatically consider new tables for query generation
